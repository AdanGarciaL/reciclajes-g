Conexión para guardar cambios

Este sitio no usa base de datos: los cambios se guardan directamente en el repositorio de GitHub. Necesitas un token de acceso para poder guardar.

Sin conectar

El token le da permiso a este panel para guardar cambios en el repositorio AdanGarciaL/reciclajes-g, solo en tu navegador. No se guarda en ningún servidor.

  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta que administra el repositorio.
  2. Elige "Only select repositories" y selecciona reciclajes-g.
  3. En "Repository permissions" activa Contents: Read and write.
  4. Genera el token y cópialo aquí. Empieza con github_pat_.

El token se guarda solo mientras dure la sesión del navegador (se borra al cerrar la pestaña).
