Ajustes de guardado

Este sitio no usa un servidor propio ni base de datos: cuando guardas cambios, se escriben directamente en el repositorio del sitio. Para eso, esta computadora necesita conectarse una sola vez con una "llave" (token) que solo tiene que configurar quien administra el repositorio (normalmente Adán). Una vez conectada, cualquier persona del equipo puede iniciar sesión y guardar cambios sin volver a tocar esta pantalla.

Revisando conexión…

¿Cómo se consigue esta llave? (solo lo hace quien administra el repositorio de GitHub)

  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta que administra el repositorio.
  2. Elige "Only select repositories" y selecciona reciclajes-g.
  3. En "Repository permissions" activa Contents: Read and write.
  4. Genera la llave y pégala arriba. Empieza con github_pat_.

La llave se guarda solo en esta computadora (en este navegador), nunca se envía a ningún otro lugar. Si la computadora se pierde o se comparte, usa "Desconectar esta computadora".
